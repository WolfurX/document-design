# Changelog

## 1.0.1 (2026-11-14)

- The prose skill this one pairs with was renamed from humanizer to
  [ai-copyedit](https://github.com/WolfurX/ai-copyedit). Every reference and link now uses the
  new name.

## 1.0.0 (2026-11-14)

First public release.

- Nine banned layout devices, the native print devices to use instead, rules for charts and
  diagrams, structural rules for editable DOCX files, and checks for documents in other
  languages.
- A five-step exit checklist that runs humanizer over the prose, resolves editorial flags, and
  rasterizes every page before sending.
- Install paths for Claude Code (plugin), the Skills CLI (about 80 agents), Claude.ai, and
  manual copy.
